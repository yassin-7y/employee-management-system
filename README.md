# Employees Management System (OOP & GUI)

A Desktop Application built using **Python** and **Tkinter** to manage specialized engineering employees (ML Engineers, DL Engineers, AI Engineers). The project demonstrates core **Object-Oriented Programming (OOP)** design patterns and multiple inheritance.

---

## ✨ Features
* **Interactive GUI:** Built with Tkinter tabs (Add, Display, Update, Delete).
* **OOP Concepts Demonstrated:**
  * **Abstraction:** Abstract Base Class (`Employee`).
  * **Inheritance & Multiple Inheritance:** `Engineer` inheriting from `Employee`, and `AI_Engineer` inheriting from both `ML_engineer` and `DL`.
  * **Encapsulation:** Private attributes for name, ID, and salary (`__name`, `__id`, `__salary`) with setter methods.
* **Employee Management Operations (CRUD):**
  * Add new employees according to specialization (ML, DL, AI).
  * View detailed employee profiles.
  * Dynamic attribute update and employee record deletion.

---

## 🛠️ Tech Stack & Requirements
* **Language:** Python 3.x
* **GUI Framework:** Tkinter (Built-in with Python)
